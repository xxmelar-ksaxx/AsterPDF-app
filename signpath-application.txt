Project description (ready to paste):
AsterPDF is an open-source desktop PDF workspace for Windows and Apple Silicon
Macs. It provides local PDF viewing, comments, page organization, text and image
editing, signatures, compression, and conversion of DOCX and common image formats
to PDF. Document processing runs locally. Windows distribution uses an Electron
application packaged as an NSIS installer, published through GitHub Releases.

Signing request (ready to paste):
We would like to apply for SignPath Foundation Windows code signing for AsterPDF.
Our public repository uses the MIT license and has downloadable Windows releases.
We are preparing a GitHub-hosted Windows build workflow so builds can be traced
to their source revision. Please advise on onboarding and the supported signing
sequence for electron-builder 26 NSIS builds: the branded application executable,
the generated uninstaller, and the final installer. Update metadata and checksums
must describe the final signed installer. We intend to require maintainer approval
for release signing and keep third-party binaries outside our project's signing
rules. Please also review our update-network behavior described below.

Network behavior to disclose:
PDFs, document content, comments, signatures, and local filenames are not uploaded.
The application automatically checks GitHub Releases roughly every 24 hours while
running, including at startup when due. It also supports manual update checks and
user-initiated update downloads. GitHub and its download infrastructure receive
normal connection metadata, including the user's IP address. There is currently
no in-app switch to disable automatic update checks. Confirm with SignPath what
installer disclosure/consent or opt-out changes they require before approval.
